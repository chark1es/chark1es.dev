A self-hostable team chat workspace: channels, DMs, threads, reactions, file sharing, roles, and voice/video calls across browser, desktop (Tauri), and mobile (Expo) clients. Each client can join multiple servers.

A single one-command installer provisions the whole stack with Docker Compose, with server-side encryption, backups, and a full documentation site. Source-available under a PolyForm noncommercial license, with a commercial tier for businesses.
